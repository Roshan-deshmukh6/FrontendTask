## Pages

- **Home** — `/`
- **Industries** — `/industries`
- **Pentakuhl** — `/pentakuhl`

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
